拓展——HttpOnly 的作用

当一个 Cookie 被标记为 HttpOnly 后：

  • JavaScript 无法访问：你无法通过 document.cookie 来读取或修改这个 Cookie。
  • 浏览器仍会自动携带：在向该 Cookie 所属的服务器发起正常的 HTTP 请求（包括由 JavaScript 发起的 fetch 或 XMLHttpRequest 请求）时，浏览器依然会自动带上它。
